# Дозор · Касса

Система оперативного учёта кассы, заказов и возвратов для селлеров маркетплейсов.

## Возможности

- **Касса (Журнал операций)**:
  - Учёт изначальной суммы в кассе с возможностью мгновенного редактирования.
  - Автоматический расчёт текущего баланса кассы с учётом всех поступлений и расходов.
  - Календарь операционных дней с отображением динамики изменений за выбранную дату.
  - Добавление и удаление действий кассы (кто совершил, описание, сумма).
- **Заказы**:
  - Мониторинг заказов с маркетплейса с фильтрацией по дате.
  - Сводная аналитика: количество заказов, сумма ожидаемых выплат, количество товаров.
  - Детализация по каждому заказу: SKU, статус (В обработке, Получен покупателем, Отменён, Возвращён), цена, субсидии, кешбэк, НДС.
- **Возвраты и отмены**:
  - Быстрый доступ к отменённым заказам.
  - Отдельный реестр возвратов и невыкупов товаров.
- **Авторизация**:
  - Аутентификация пользователей с хранением сессии.

## Запуск в разработке

```bash
npm install
npm run dev
```

Приложение запускается на порту 3000 (`http://localhost:3000`).

## Сборка

npm run build
